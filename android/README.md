# CartFlow Android App / APK Guide

CartFlow-কে অ্যান্ড্রয়েড ফোনে অ্যাপ হিসেবে ব্যবহার করার জন্য ৩টি সহজ ও কার্যকর উপায় প্রস্তুত করা হয়েছে:

---

## উপায় ১: PWA (কোনো বিল্ড বা সফটওয়্যার ছাড়াই সরাসরি ফোনে ইনস্টল) — সবচেয়ে সহজ ও সুপারিশকৃত

CartFlow-এ ইতোমধ্যে **Progressive Web App (PWA)** এবং **Service Worker** সম্পূর্ণ সক্রিয় করা হয়েছে। 

### ফোনে ইনস্টল করার নিয়ম:
1. আপনার কম্পিউটার এবং অ্যান্ড্রয়েড ফোনটি একই ওয়াইফাই (WiFi) নেটওয়ার্কে কানেক্ট করুন।
2. কম্পিউটারে কমান্ড প্রম্পট/টার্মিনালে রান করুন:
   ```bash
   php artisan serve --host=0.0.0.0 --port=8000
   ```
3. অ্যান্ড্রয়েড ফোনের **Google Chrome** ব্রাউজারে প্রবেশ করে আপনার কম্পিউটারের লোকাল আইপি অ্যাড্রেস লিখুন:
   ```
   http://192.168.1.22:8000
   ```
   *(অথবা যদি লাইভ ডোমেইন বা Herd Share ব্যবহার করেন, সেই লিঙ্কটি খুলুন)*
4. ক্রোম ব্রাউজারে নিচে স্বয়ংক্রিয়ভাবে **"Add CartFlow to Home screen"** বা **"Install app"** পপআপ আসবে (অথবা ক্রোমের থ্রি-ডট ৩-বিন্দু মেন্যুতে ট্যাপ করে **"Install app" / "Add to Home screen"** চাপুন)।
5. সাথে সাথে আপনার অ্যান্ড্রয়েড ফোনের হোম স্ক্রিনে ও অ্যাপ ড্রয়ারে **CartFlow** অ্যাপের আইকন যুক্ত হয়ে যাবে। এটি সম্পূর্ণ ফুলস্ক্রিনে ঠিক নেটিভ অ্যাপের মতো চলবে (ব্রাউজারের কোনো অ্যাড্রেস বার বা নেভিগেশন বার থাকবে না)।

---

## উপায় ২: Android Studio দিয়ে সরাসরি `.apk` ফাইল তৈরি

`android/` ফোল্ডারে একটি কমপ্লিট অ্যান্ড্রয়েড স্টুডিও প্রজেক্ট প্রস্তুত করা হয়েছে।

### প্রজেক্টের বৈশিষ্ট্য:
- **ফুলস্ক্রিন WebView**: ব্রাউজার বার মুক্ত মসৃণ ইন্টারফেস।
- **Pull-to-Refresh**: ওপর থেকে নিচে টেনে পেজ রিফ্রেশ করার সুবিধা।
- **হার্ডওয়্যার ব্যাক বাটন**: ফোনের ব্যাক বাটনে চাপলে সরাসরি অ্যাপ বন্ধ না হয়ে পেজের আগের ধাপে ফেরত যাবে।
- **অফলাইন রিকভারি স্ক্রিন**: ওয়াইফাই বা ইন্টারনেট বিচ্ছিন্ন হলে সুন্দর বাংলা ও ইংরেজি রিকভারি এবং "আবার চেষ্টা করুন" বাটন।
- **ক্যামেরা ও ফাইল আপলোড**: রসিদ ও খাবার ছবি আপলোড সাপোর্ট।

### APK বিল্ড করার নিয়ম:
1. আপনার কম্পিউটারে **Android Studio** ইনস্টল করা থাকলে Android Studio ওপেন করুন।
2. **Open an Existing Project** সিলেক্ট করে `c:\Users\farza\Herd\cartmanager\android` ফোল্ডারটি ওপেন করুন।
3. যদি লাইভ সার্ভারের ডোমেইন পরিবর্তন করতে চান, তাহলে `android/app/src/main/res/values/strings.xml` ফাইলে গিয়ে `default_url`-এ আপনার লাইভ লিঙ্ক দিন:
   ```xml
   <string name="default_url">https://your-domain.com</string>
   ```
4. অ্যান্ড্রয়েড স্টুডিওর উপরের মেন্যু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** এ ক্লিক করুন।
5. বিল্ড শেষ হলে নিচে **"locate"** বাটনে ক্লিক করলেই আপনার কাঙ্ক্ষিত `app-debug.apk` ফাইল পেয়ে যাবেন!

## উপায় ৩: ক্লাউড / অনলাইন APK জেনারেটর (১ ক্লিকে APK ডাউনলোড)

যদি আপনার কম্পিউটারে অ্যান্ড্রয়েড স্টুডিও বা জাভা ইনস্টল না থাকে:
1. সাইটটি লাইভ বা **Herd Share** দিয়ে পাবলিক ইউআরএল তৈরি করুন:
   ```bash
   herd share
   ```
2. ব্রাউজারে যান: [PWABuilder (by Microsoft)](https://www.pwabuilder.com/)
3. আপনার CartFlow-এর ইউআরএল দিন এবং **Start** চাপুন।
4. সাইটটি CartFlow-এর `manifest.json` ও আইকন স্বয়ংক্রিয়ভাবে ডিটেক্ট করবে।
5. **Package for Android** বাটনে ক্লিক করলেই সরাসরি রেডিমেড `.apk` এবং `.aab` (Play Store এর জন্য) ডাউনলোড হয়ে যাবে!
